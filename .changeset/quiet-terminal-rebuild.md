Rebuild Quiet as a Grok Build-inspired terminal presentation layer with a responsive welcome card, boxed native editor, transient palette, compact status area, and restrained tool activity.
Keep native Pi execution and keyboard bindings, preserve mixed-tool renderers on expansion, and reconstruct folded activity from the active branch.

Breaking: requires Pi 1.4 or newer and removes the built-in tool-override fallback.
Quiet now owns terminal chrome while enabled; disable overlapping presentation extensions for the closest match.
Unknown tools no longer fold together, and collapsed exploration groups show their three most recent members.
The existing `quiet.json` preference remains compatible.
